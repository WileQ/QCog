# Where the quantum account does better than the classical one

A small, self-contained study: five cases, each with data, fits and a verdict, reported in
[`REPORT.md`](REPORT.md) with its numbers in [`results.json`](results.json) and one graph per case in
[`figures/`](figures/).

```bash
python studies/quantum_advantage/run_study.py                    # write the report, results and figures
python studies/quantum_advantage/run_study.py --no-figures --print   # print only
python studies/quantum_advantage/run_study.py --cases correlated-crowd question-order
```

## What "better" means here

"Quantum cognition is superior" is a claim that can be checked or be empty. This study uses three precise senses
and labels every case with the one it uses:

| sense | meaning | why it is the strongest kind |
| --- | --- | --- |
| **S1 imposed impossibility** | the pattern lies outside the classical family, so no classical parameters reproduce it | it is a statement about the formalisms, not about a fit |
| **S2 parameter-free prediction** | the quantum model predicts a quantity it did not fit, and the classical account gets it wrong | no free parameters to hide behind |
| **S3 parsimony and unification** | both accounts can fit, but the quantum one explains more of the data with the same state | weaker, and labelled as such |

## The five cases

| case | sense | headline result |
| --- | --- | --- |
| Question order (two survey questions, both orders) | S1 | held-out prediction error 0.12 against 0.36; the classical identity is violated by 0.10 |
| Conjunction fallacy (Linda) | S1 | the conjunction exceeds the classical bound by 0.13, and no classical model can pass that bound |
| Disjunction effect (unknown opponent) | S1, verified over 200 random bipartite states | sure-thing violation 0.29 in the coherent design, 1e-16 in every factorised one |
| Correlated crowd (Condorcet) | S2 | vote-count variance 5.9 against the independent model's 1.5 at the same mean |
| Superposition versus ignorance | S2 | a distribution-only account is wrong by 0.50 on the second question, with no parameter to adjust |

## What the study does *not* claim

* The data are **simulated from the quantum models**. That is deliberate: the point is to show where the classical
  family *cannot* follow, which is a statement about the formalisms and needs no human participants. It is **not**
  evidence that people are quantum.
* Two of the five cases include a classical model that is **not rejected**: a classical model with order-dependent
  joints (case 1) and a beta-binomial, the classical model of over-dispersion (case 4). Both are reported as
  surviving, with the reason the quantum account is still preferred (parsimony and unification, not likelihood).
* Every case states, in the report, what it does not show. The library's standing caveats apply: these models
  describe response probabilities, not brains.

## Reproducing it

The data are drawn with a fixed seed, so the numbers are stable; the figures and the report are regenerated by
the same command. The study uses only the library's public API — the models, the fitter, the classical baselines,
the metrics and the figure layer — so it doubles as a worked example of using Q-Cog for a comparative claim.
