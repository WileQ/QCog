0:00 - 0:15 | The problem, in one breath

Screen: the README title block, then the terminal.

"Quantum cognition asks a specific question: can human judgements be described by a probability theory in which questions do not commute? If they can, then things that look like errors become structural. Q-Cog makes that programme testable, explainable and comparable with classical models - in one library, built on Qiskit."

0:15 - 0:45 | The flagship result

Screen: run python demos/examples/01_first_steps.py (or paste the four-line example) and show the output.

from qcog import basis_state, question, run_sequence, order_effect, qq_equality
belief = basis_state(0, 2)
a, b = question(0.955, 0.0, "A"), question(3.14159/2, 0.0, "B")
print(order_effect(run_sequence(belief, [a, b]), run_sequence(belief, [b, a]), "A", "B").summary())
print(qq_equality(run_sequence(belief, [a, b]), run_sequence(belief, [b, a]), "A", "B").summary())
"Two questions. Asked in one order, p(A) is 0.79; asked in the other, 0.50. A classical model - one distribution over the two answers - forces those to be equal. And the model makes a prediction with no free parameters: the probability of answering both questions the same way is identical in the two orders. It holds to machine precision."
