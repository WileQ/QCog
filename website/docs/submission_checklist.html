Non-obvious requirements worth double-checking

  • "Results from IonQ's simulators or hardware neither add nor subtract points." Nothing in the submission depends on IonQ credentials; the default path is local. Verified by running the catalogue with the default backends.
  • "Every project must run on a free local simulator." qcog evidence finishes in about a minute on a laptop and never touches the network; qcog report regenerates every artefact offline.
  • Attribution. The line This effort is supported by Qollab & IonQ appears in the README, the generated reports (report.py footer), the explorer and the project page - the rules ask for it on the project.
  • Twelve-month availability. The repository is self-contained (no external data or services); keep the repo and the video link alive.
  • Payment method for awards. Account-level detail, not part of this repository - remember to add it.
