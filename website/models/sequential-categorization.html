Sequential categorisation: why repeated labels stabilise a judgement

module B: Logic, concepts and memoryintermediateslug: sequential-categorization

Repeated labels reproduce the first answer with probability 0.934 (independent baseline 0.716).

What it asks

Does presenting several category labels in a row change how the category is judged, and in which direction?

How it works

Repeated projective or unsharp measurements of the same question: the state is driven towards the eigenstate of the answer, the quantum Zeno effect.

Classical baseline. Independence: each judgement is drawn from the same distribution, so the response trajectory is flat in expectation.

qcog run sequential-categorization

What this run shows

  • After the first label has been answered 'yes', the same answer is reproduced with probability 0.934 on the last of 6 labels; the independent-judgement baseline is 0.716.
  • Consecutive labels agree with probability 0.716, against the independent baseline 0.593: repeated questioning makes the judgement more stable, not noisier (a Zeno effect in a categorisation task).
  • The unconditional answer rate stays flat, which is exactly why the stability has to be measured conditionally - a point the two series in the figure make visible.
  • How much stabilisation appears is controlled by how decisive each label is: with weak labels the anchored series relaxes back towards the baseline, which is the classical limit.

What this does not claim

  • This is a model of response probabilities, not a claim about what the brain does.
  • A quantum model only means the data are described by a quantum probability space; classical models may fit equally well, and the classical baseline is reported for that reason.
  • The Zeno effect here is a property of repeated measurement; it does not require the labels to carry new information.
  • The exact engine enumerates one path per label sequence (2 per label), so the parameter is capped at twelve labels; beyond that the sampled backend gives the same distribution with shot noise.
